# 🎮 HTML5 Canvas 뱀서라이크 (Vampire Survivors Web) - 34단계 프롬프트 엔지니어링 프로젝트

게임 프로그래밍 두 번째 프로젝트 과제 제출용 저장소입니다.  
단순한 기본 도형 추격 게임(Step 00)에서 출발하여, **총 34개의 의미 있는 프롬프트 담금질(업그레이드)**을 거쳐 완성된 HTML5 `Canvas` 기반 서바이벌 액션 웹 게임입니다.

---

## 🚀 실행 방법 및 파일 구성
1. **`step00_base_game.html`**: 업그레이드 전 최초 원본 게임 (파란 사각형과 빨간 사각형의 기본 이동/충돌)
2. **`index.html`**: 34단계 업그레이드가 모두 반영된 최종 웹 게임 (**상단 드롭다운 컨트롤러를 통해 Step 00 ~ Step 34의 단계별 변화를 실시간으로 전환하며 확인 및 캡처 가능**)

---

## 🛠️ 핵심 기술 스택 (Pure Vanilla JS & HTML5 Canvas)
- **렌더링 엔진**: HTML5 `Canvas` 2D Context (외부 이미지/오디오 에셋 없이 순수 도형, 그라데이션, 파티클 연산으로 구현)
- **물리 및 수학 연산**: `Math.atan2`, `Math.cos`, `Math.sin`, `Math.hypot`을 활용한 8방향 정규화 이동, 회전 칼날 공전 궤도, 위협도 가중치 기반 스마트 오토 타겟팅 탄도학, 넉백 물리 구현
- **사운드 합성**: `Web Audio API` (`AudioContext`, `OscillatorNode`) 기반 실시간 타격음 및 레벨업 효과음 합성
- **데이터 영속성**: 브라우저 `localStorage`를 이용한 보유 골드 및 최고 기록 자동 저장
