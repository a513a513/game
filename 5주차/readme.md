[<mark>가변 인수</mark>]
가변 인수는 함수 호출 시 인수의 개수가 정해져 있지 않고 변할 수 있는 인수입니다.
printf(const char *format, ...);를 보면 format은 고정된 인수이고, ...은 가변 인수를 의미합니다.
scanf도 마찬가지로 scanf("%d %d %d", &a1, &a2, &a3)처럼 3개의 변수를 받을 수도 있고, scanf("%d %d", &a1, &a2)처럼 2개의 변수를 받을 수도 있습니다.



  
[ <mark>배열 크기 할당</mark> ]  
배열을 사용할 때 가장 큰 문제는 배열의 크기를 미리 정해야 한다는 것입니다. 미리 정한 배열의 크기보다 적게 사용한다면 사용하지 않는 메모리가 낭비될 수 있습니다. 
따라서 메모리를 효율적으로 사용하기 위해서는 프로그램 실행에 필요한 만큼의 메모리를 확보하는 방법이 필요합니다. 이를 해결하기 위해 정보가 생성될 때마다 필요한 
만큼의 메모리를 할당하고, 해당 정보가 더 이상 필요하지 않게 되면 메모리를 해제하여 다른 정보를 저장할 수 있도록 합니다.
