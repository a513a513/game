vscode에서 c컴파일하는방법

윈도우나 vscode에선 c컴파일을 자체적으로 지원하지 않는다 그럼으로
우선 c컴파일을 하기위해선 minGW나 MSYS2인 컴파일러를 다운로드 해야한다 (https://www.msys2.org/)
사이트 접속하여 최신상태의 .exe파일을 다운로드 후 실행
환경변수 편집을 해줘야 한다 고급시스템설정을 윈도우 검색에서 검색하여 고급 탭의 환경 변수를 클릭
시스템 변수항목의 path 더블 클릭후 새로 만들기 클릭하여 다운로드한 MSYS2의 설치 경로를 추가 한 뒤
cmd를 실행해서 g++ --version과 gdb --version 두 명령어를 실행 하여 설치가 된것을 확인한다.
그 뒤 vscode를 실행해서 아무이름.c 파일을 만든뒤
#include <stdio.h>

int main(){
  printf("Hello World");
}
파일을 만든뒤 ctrl + ` 키를 눌러 터미널을 켜준다음 gcc 아무이름.c -o 아무이름.exe 입력하면 아무이름.exe 파일이 만들어 진다.
그뒤 ./아무이름.exe 를 입력하면 exe파일이 실행되는것을 볼수 있다.

# VS Code에서 C언어 컴파일 및 실행 가이드 (Windows)

Windows와 VS Code는 기본적으로 C언어 코드를 실행 파일(.exe)로 만들어주는 '컴파일러'를 내장하고 있지 않습니다. 따라서 **MSYS2**를 통해 GCC 컴파일러를 직접 설치하고 연결해 주어야 합니다.

## 1. 컴파일러(MSYS2) 다운로드 및 설치
1. [MSYS2 공식 사이트](https://www.msys2.org/)에 접속하여 최신 `.exe` 설치 파일을 다운로드하고 기본 설정대로 설치를 완료합니다.
2. 설치 완료 후 열리는 MSYS2 터미널 창에 아래 명령어를 입력하여 **실제 GCC 컴파일러를 설치**합니다. 
   *(설치 진행을 묻는 메시지가 나오면 `Y`를 입력하고 엔터를 누르세요.)*
   ```bash
   pacman -S mingw-w64-ucrt-x86_64-gcc
   ```

## 2. 환경 변수 설정
컴퓨터가 설치된 컴파일러를 어디서든 실행할 수 있도록 경로를 등록하는 과정입니다.
1. 윈도우 검색창에 **고급 시스템 설정 보기**를 검색하여 실행합니다.
2. **[고급]** 탭 하단의 **[환경 변수]** 버튼을 클릭합니다.
3. 아래 **'시스템 변수'** 목록에서 `Path` 항목을 찾아 더블 클릭합니다.
4. **[새로 만들기]**를 클릭하고 아래의 컴파일러 설치 경로를 추가한 뒤 **[확인]**을 눌러 모두 닫아줍니다.
   * 경로: `C:\msys64\ucrt64\bin`

## 3. 설치 확인
1. 윈도우 검색창에 `cmd`를 검색해 **명령 프롬프트**를 실행합니다.
2. 아래 명령어를 입력했을 때, 버전 정보가 길게 출력된다면 성공적으로 설치된 것입니다.
   ```cmd
   gcc --version
   ```

## 4. VS Code에서 코드 작성 및 실행
1. VS Code를 실행하고 원하는 이름으로 C언어 파일(예: `test.c`)을 생성합니다.
2. 아래의 기본 코드를 작성하고 저장(`Ctrl + S`)합니다.
   ```c
   #include <stdio.h>

   int main() {
       printf("Hello World\n");
       return 0;
   }
   ```
3. **`Ctrl + \``(백틱)** 키를 눌러 VS Code 하단의 터미널을 엽니다.
4. 아래 명령어를 입력하여 코드를 컴파일(.exe 파일 생성)합니다.
   ```bash
   gcc test.c -o test.exe
   ```
5. 컴파일이 완료되면 아래 명령어로 생성된 프로그램을 실행합니다.
   ```bash
   ./test.exe
   ```
   *(터미널에 `Hello World`가 출력되면 성공입니다.)*
